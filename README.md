# Everyday Meal Planner

Files:
- `index.html` — app UI and logic
- `meals.json` — starter meal data

## Run locally
Because `index.html` loads `meals.json`, open it through a local server:

```bash
python3 -m http.server 8000
```

Then open:

```txt
http://localhost:8000
```

## Host on GitHub Pages
Upload `index.html` and `meals.json` to the root of your repo, then enable GitHub Pages from Settings → Pages.
